# Project Setup

## Start the System

To start all services, run:

```bash
docker compose up
```
 To run the services in detached mode:
```bash
docker compose up -d
```

## Stop the System

To stop all running services:

```bash
docker compose down
```
## Stop the System and Remove Volumes

To stop the services and remove associated volumes:

```bash
docker compose down -v
```
